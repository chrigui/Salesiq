01 · What it is

One platform, any vertical, every decision

SalesIQ is an enterprise SaaS platform that helps companies walk customers through complex purchasing decisions using interactive presentations, AI, and visual storytelling. A big-screen customer display sets the scene, a phone companion lets the salesperson drive it in real time, a self-explaining AI engine recommends and justifies the best fit, and per-tenant admin consoles run the whole thing.

Everything industry-specific — the questions asked, the inventory shown, the scoring logic, the branding — lives in a single configuration “pack.” The engine and every screen are entirely pack-driven, so the same product serves real estate, automotive, private aviation, yachts, medical, insurance and beyond without code changes. It is multi-tenant, modular, and built to scale.

03 · The platform

Five surfaces, one live session

Each surface has a distinct job; together they run the whole customer conversation.

i./display

Customer Experience Display

The full-screen, cinematic presentation the customer sees. An Interactive Lifestyle Map is the hero — 3D terrain, atmosphere, day/night, walking routes and floating AI storytelling. Dark and premium; never looks like a dashboard.

ii./companion

Sales Companion

The phone the salesperson holds. Asks questions, jumps sections, runs natural-language search, generates proposals and captures leads — every action updates the display instantly.

iii./dashboard

Company Dashboard

Each tenant’s admin: a visual builder for questions, inventory, scoring rules, branding and map scenes, plus live leads and analytics. Clean, light, fully responsive.

iv./admin

Platform Administration

The master console: tenants, subscriptions, MRR/ARR, usage by vertical and system health — the operator’s view across every company on the platform.

v./api/ai

AI Decision Engine

Scores inventory against answers and returns self-explaining recommendations, plus natural-language customer search. Claude-powered when configured, with a deterministic fallback that always works.

The customer display stays in lockstep with the companion through a real-time sync bus — same-device instantly, cross-device via QR pairing.
